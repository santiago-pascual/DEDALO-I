# Scientific limitations and open questions

- Full frozen P4 reproduction requires component input tapes and the freeze manifest omitted from the reviewed snapshot.
- P5 and NBM-B certification need a separate approved release evidence bundle; no incremental alpha claim is made.
- Frozen model fitting/decoding differs from causal production inference. Full-period pseudo-live validation remains incomplete.
- Entry-ordered R curves are not mark-to-market account equity. Execution, costs, concurrency and calendar conventions require matched evidence.
- Historical data quality acceptance is distinct from strict coverage certification; contract mapping and roll assumptions must be reviewed separately.
- Parameter selection, multiple testing, serial dependence and raw component identity require separate robustness evidence.
- The latest forward ledger and runtime identity were not inspected. No actual paper or live performance is inferred.
- The economic study is conditional on reconstructed profiles and dated assumptions; bootstrap sampling error does not encompass structural uncertainty.
- Static inspection of the private snapshot found two syntax parse failures among 631 Python files; operational relevance was not established. No private tests were run during this review.
- AI assistance is disclosed. Exact individual coding contributions are not independently verified.
